## Опис завдання
Метою роботи є створення модульної програми на C++, яка в реальному часі захоплює відеопотік з камери, обробляє його за допомогою різних фільтрів OpenCV та дозволяє інтерактивно керувати параметрами відображення.

## Основні можливості
* **Модульна архітектура:** Кожна логічна частина (камера, обробка, клавіші, дисплей) винесена в окремий клас.
* **Різні режими обробки:**
    * Інверсія кольорів.
    * Розмиття за Гаусом (Gaussian Blur).
    * Детектор меж Кенні (Canny Edge Detection).
    * Перетворення у відтінки сірого (Grayscale).
* **Інтерактивність:** * Керування режимами через клавіатуру.
    * Регулювання яскравості за допомогою повзунка (Trackbar).
    * Текстовий оверлей з інформацією про поточний режим.

## Вимоги до системи (Requirements)
Для успішного білду та запуску програми на "чистій" системі Ubuntu необхідні:
* **ОС:** Linux (Ubuntu 22.04 LTS або новіша рекомендовано).
* **Компілятор:** GCC 11+ або Clang (з підтримкою C++17).
* **Система збірки:** CMake 3.10+.
* **Бібліотеки:** OpenCV 4.x (модулі core, imgproc, highgui, videoio).
* **Апаратне забезпечення:** Веб-камера (або прокидання USB-пристрою у віртуальну машину VMware).

## Інструкція з налаштування та запуску

Програма підтримує повну автоматизацію розгортання через bash-скрипти:

1. **Встановлення залежностей:**
   ```bash
   ./preinstall.sh
   
2. **Компіляція проєкту:**
    ```bash
    ./build.sh
     
3. **Запуск програми:**
    ```bash
    ./run.sh
    
##Керування програмою

* 0 — Оригінальне зображення (скидання фільтрів).

* 1 — Інверсія кольорів (bitwise_not).

* 2 — Gaussian Blur.

* 3 — Canny Filter (межі об'єктів).

* 4 — Grayscale (чорно-білий режим).

* Esc — Завершення роботи програми.

* Slider "Brightness" — регулювання яскравості в реальному часі.
