## Опис завдання
Метою роботи є створення інтерактивної програми для візуалізації гармонійного сигналу з накладеним шумом та його подальшої фільтрації.

Програма реалізує:
1. Генерацію гармоніки вигляду:  
   (y(t) = A*sin(ωt +φ))
2. Накладання випадкового шуму з регульованим середнім значенням та дисперсією.
3. Цифрову фільтрацію сигналу за допомогою фільтра Баттерворта (нижніх частот).
4. Інтерактивний інтерфейс для керування параметрами в реальному часі.

## Інструкція користувача
* Амплітуда, Частота, Фаза: Слайдери змінюють параметри чистої синусоїди.
* Середнє значення шуму: Зміщує шум вгору або вниз по осі Y.
* Дисперсія шуму: Змінює інтенсивність (розмах) шуму.
* Фільтр (зріз): Регулює частоту відсікання фільтра. Чим нижче значення, тим гладшим буде сигнал.
* Чекбокс "Шум": Дозволяє приховати або показати зашумлений сигнал.
* Кнопка "Скинути": Повертає всі повзунки до початкових значень.
Зауваження: При зміні параметрів гармоніки (амплітуди чи частоти) малюнок шуму залишається незмінним. Шум перегенерується лише при зміні параметрів самого шуму.
