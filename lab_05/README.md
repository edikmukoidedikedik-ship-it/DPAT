## Опис завдання
Цей проєкт є веб-додатком, створеним за допомогою бібліотеки Streamlit. Він призначений для зручного відображення, фільтрації та візуалізації результатів дослідження часових рядів вегетаційних індексів (VCI, TCI, VHI) для різних областей України (на основі даних з лабораторної роботи №2).

## Системні вимоги
- Python 3.9+
- Наявність встановлених бібліотек із `requirements.txt`

## Інструкція з налаштування та запуску

1. Відкрийте термінал у директорії `lab_05`.
2. Створіть віртуальне середовище:
   ```bash
   python -m venv venv
3. Активуйте віртуальне середовище:
    ```bash
    .\venv\Scripts\activate

4. Встановіть необхідні залежності:
    ```bash
    pip install -r requirements.txt
5. Запустіть скрипт додатку:
    ```bash
    streamlit run lab5.py

Додаток автоматично відкриється у вашому браузері за адресою http://localhost:8501.
